## Short Product Description

PortTrack is an educational stock investment simulation platform. Lecturers create rooms and allocate virtual capital; students use that capital to trade stocks using market quote data without risking real money. The system records transactions and automatically updates cash, holdings, NAV, profit/loss, and returns. Lecturers can monitor the simulation and evaluate student performance through dedicated management pages.

## Problem the Product Solves

Students need a realistic environment in which to practice investment and portfolio management without financial risk. Lecturers need a centralized way to organize simulations, review investment decisions, and evaluate results transparently. PortTrack addresses both needs in one platform.

## Target Users

- Portfolio Management and finance lecturers.
- Students learning investment and portfolio management.
- Users participating in classroom exercises, course projects, or educational simulations.

## Main Features

- Registration, login, security, and role-based access.
- Public/private room creation and room-code participation.
- Virtual stock trading with market-hours and T+2 checks.
- Cash, holdings, NAV, profit/loss, and return tracking.
- Portfolio summaries and transaction history.
- Lecturer monitoring, submissions, and leaderboard access.

## How to Run the Product

1. Open https://port-track-xi.vercel.app/.
2. Register or log in as a lecturer or student.
3. A lecturer creates a simulation room; students join using its code.
4. Students trade stocks and review their portfolios.
5. The lecturer reviews participants, transactions, submissions, and rankings.

## Data Notes

PortTrack uses user-generated records, virtual capital, and external Vietnamese stock quote data. Application records are stored in MySQL. No real money, database passwords, JWT secrets, or private API credentials are published in the repository.
